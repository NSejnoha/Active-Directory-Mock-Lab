# Active-Directory-Mock-Lab
These are the steps I took to create a mock Active Directory lab using Oracle VirtualBox to create 2 VMs: One running Windows Server 2019 to act as a Domain Controller, with the second VM running Windows 10 acting as a client on the domain.
I utilized a guide created by [Josh Madakor](https://www.youtube.com/@JoshMadakor) on YouTube to aid in the creation and understanding of this process, while troubleshooting issues along the way by referencing technical documentations and utilizing my knowledge of TCP/IP and subnetting.
